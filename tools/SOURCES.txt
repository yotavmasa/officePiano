./gradlew --no-daemon --max-workers=2 -Dorg.gradle.jvmargs=-Xmx1536m -PtargetOS=linux-arm64 :app:installDist
Audiveris 5.11.0 requires Java 25; its Gradle files select ARM64 Tesseract/Leptonica dependencies.
Installer retains source in .build/audiveris-5.11.0 and the runnable distribution in tools/audiveris.

Tools run locally. Recognition can misread notes/rhythms, especially low-resolution photos and complex scores. Each named PDF piece is converted independently using its selected pages; multiple exported movements are rejected. Original source files are retained.
